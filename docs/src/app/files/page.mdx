# Files & Clipboard

agent-browser can upload files, capture downloads, read local files through `file://` URLs, write PDFs and screenshots, and interact with the browser clipboard.

## Upload files

```bash
agent-browser snapshot -i
agent-browser upload @e4 ./invoice.pdf
agent-browser upload @e4 ./front.png ./back.png
```

The selector must resolve to a file input. Multiple file paths are accepted for multi-file inputs.

## Downloads

```bash
agent-browser download @e5 ./report.csv
agent-browser click @e6
agent-browser wait --download
agent-browser wait --download ./archive.zip --timeout 30000
```

`download` clicks the element and saves the first newly observed download from its page or frames to the requested path. Selection follows download start order; it does not establish which network request the click caused. `wait --download` returns the oldest retained unreported download from the current page or its frames, including one that completed before the wait began. With a path, it saves that file there; without one, it returns the actual saved path.

Each completed download or reported cancellation is consumed once. Canceled downloads return an error; a timeout leaves the download available for a later wait. Once selected, a download retains its own identity, so another download's completion or cancellation cannot settle that wait. The browser retains up to 256 recent terminal records. A wait reports an unavailable download if its selected record leaves that history.

JSON results include the absolute `path`, download `guid`, `suggestedFilename`, `status: "completed"`, and `receivedBytes`. Paths refer to the machine running the browser.

Set a default download directory for browser-initiated downloads:

```bash
agent-browser --download-path ./downloads open https://app.example.com
```

Agent-browser-managed Chromium observes downloads throughout its lifetime. Without `--download-path`, its downloads go to a temporary directory that is cleaned up when the browser closes.

Attaching to an existing browser leaves its download settings unchanged. An explicit `download` configures only the active context, using the destination's parent directory as retained storage. `wait --download` alone never changes an attached browser's settings.

## Screenshots and PDFs

```bash
agent-browser screenshot ./page.png
agent-browser screenshot --full ./page-full.png
agent-browser screenshot --screenshot-format jpeg --screenshot-quality 80 ./page.jpg
agent-browser pdf ./page.pdf
```

## Local files

```bash
agent-browser --allow-file-access open file:///Users/me/report.pdf
agent-browser --allow-file-access open file:///path/to/page.html
agent-browser screenshot ./local-file.png
```

`--allow-file-access` is Chromium-only. It allows `file://` pages to load and access other local files through browser APIs such as `fetch` and XHR.

## Clipboard

```bash
agent-browser clipboard read
agent-browser clipboard write "Hello, world"
agent-browser clipboard copy
agent-browser clipboard paste
```

`copy` and `paste` simulate the platform keyboard shortcuts for the current selection or focused element. Use `write` when you want to set clipboard text directly.
